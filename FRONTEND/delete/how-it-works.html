분석 프로세스

FTOGuard는 어떻게 분석하나요?

제품 정보를 입력하는 것만으로 AI가 특허 침해 가능성을 단계별로 분석합니다.
분석 유형에 따라 각각 최적화된 프로세스로 결과를 제공합니다.

⚡ 빠른 분석 🔒 보안 처리 📋 리포트 제공 💡 회피 설계 제안

특허·실용신안 분석 프로세스

화장품 성분·조성물·기술 구성을 입력하면 등록 특허와 자동으로 비교합니다.

1

제품 정보 입력

출시 예정인 화장품의 성분, 조성 비율, 제형 방식 등을 자유롭게 입력합니다.
전문 용어를 몰라도 괜찮습니다. 아는 만큼 입력하면 AI가 분석을 시작합니다.

✍️ 이런 내용을 입력하세요

  • · 주요 성분 및 함량 (예: 나이아신아마이드 5%)
  • · 제품의 목적·효과 (예: 미백, 보습, 자외선 차단)
  • · 특이 제조 방식이 있다면 간략히 기재

💡 입력 예시

"나이아신아마이드 5%, 히알루론산 0.5%를 포함한 피부 미백 세럼을 만들려고 합니다."
2

유사 특허 자동 검색

AI가 국내외 화장품 특허 데이터베이스에서 입력된 제품과 유사한 특허를 자동으로 찾아냅니다.

KIPRIS
국내 특허 DB
USPTO
미국 특허 DB
EPO
유럽 특허 DB
3

구성요소 비교 분석

특허의 핵심 보호 범위와 내 제품의 구성요소를 항목별로 대조합니다.
어떤 성분·기술이 특허와 겹치는지 명확하게 확인할 수 있습니다.

구성요소 대비표 예시
특허 구성요소 내 제품 해당 여부
나이아신아마이드 1~10% 나이아신아마이드 5% 해당
히알루론산 0.01~1% 히알루론산 0.5% 해당
아스코르브산 0.1~5% 미포함 미해당
4

침해 가능성 판단

특허법 원칙에 따라 실질적인 침해 여부를 판단합니다.
단순히 성분이 겹쳐도 모든 구성요소를 충족해야 침해로 판단되기 때문에, 정확한 분석이 가능합니다.

🔍 모든 구성요소 충족 원칙

특허의 모든 핵심 성분·구성을 내 제품이 포함할 때만 침해로 판단합니다. 하나라도 빠지면 침해가 아닙니다.

⚖️ 유사 범위 검토

수치가 약간 다르거나 성분을 살짝 변형해도 실질적으로 같은 효과라면 침해 검토 대상이 될 수 있습니다.

5

결과 및 회피 방안 제공

분석 결과를 4가지 등급으로 알려주고, 침해 위험이 있을 경우 제품을 안전하게 출시할 수 있는 방향을 제안합니다.

✅

침해 가능성이 낮습니다

현재 구성으로 출시를 진행해도 될 것으로 분석됩니다.

⚠️

전문가 추가 검토 권고

일부 요소가 특허와 유사합니다. 변리사 검토를 권장합니다.

🚨

침해 가능성이 높습니다

성분·구성을 변경하거나 특허권자와 협의가 필요합니다. AI가 회피 방안을 제안합니다.

ℹ️

추가 정보 필요

정확한 판단을 위해 제품 정보를 더 구체적으로 입력해 주세요.

디자인 분석 프로세스

입력 방식에 따라 AI가 최적의 분석 경로를 자동으로 선택합니다.

📸 사진 입력

제품 이미지를 업로드하면 VLM이 시각적으로 분석하여 유사 디자인을 검색하고 FTO 리포트를 생성합니다.

✍️ 텍스트 입력

질문이나 설명을 입력하면 AI Agent가 의도를 파악하여 이미지 검색, 일반 답변, 웹 검색 중 적절한 도구로 응답합니다.

사진 입력 경로

1

사진 업로드

출시 예정인 화장품 용기·패키지 사진을 업로드합니다.
여러 각도의 사진을 첨부할수록 더 정확한 분석이 가능합니다.

📸 권장 이미지

  • · 정면·측면·상단 등 다각도 촬영
  • · 용기 전체 형태가 잘 보이는 사진
  • · PNG, JPG, JPEG, WEBP 형식

✍️ 외관 설명 (선택)

"각진 사각형 토너 병, 투명 유리 재질, 블랙 펌프 헤드"처럼 특징을 함께 입력하면 더욱 정확합니다.
2

VLM 이미지 분석 → 유사 디자인 10개 반환

VLM(Vision Language Model)이 업로드된 사진의 형태·색채·장식 요소를 분석하고, 등록 디자인 DB에서 가장 유사한 10개를 추출하여 썸네일로 제시합니다.

🔲

전체 형태

원통형, 사각형, 타원형 등 실루엣 분석

🎨

색채·재질

표면 색상, 투명도, 재질감 분석

✨

장식 요소

패턴, 라인, 캡 형태 등 세부 요소

3

유사 디자인 1개 선택

반환된 10개의 유사 디자인 중 내 제품과 가장 비슷하다고 판단되는 1개를 선택합니다. 선택한 디자인이 심층 비교 분석의 기준이 됩니다.

i 출원번호, 등록일, 유사도 수치가 함께 표시되어 선택에 참고할 수 있습니다.
4

상세 비교 분석 → FTO 리포트 생성

업로드한 사진과 선택한 등록 디자인을 항목별로 정밀 비교하여 침해 가능성을 판단하고, 차별화 포인트와 회피 방향이 포함된 FTO 리포트를 생성합니다.

✅

침해 가능성이 낮습니다

기존 등록 디자인과 충분히 구별됩니다. 현재 디자인으로 진행 가능합니다.

⚠️

전문가 추가 검토 권고

일부 외관이 유사합니다. 디자인 전문가나 변리사 확인을 권장합니다.

🚨

침해 가능성이 높습니다

등록 디자인과 외관이 매우 유사합니다. AI가 구체적인 차별화 포인트를 제안합니다.

텍스트 입력 경로

1

텍스트 입력

디자인 검색 요청, 일반 질문, 또는 관련 정보 검색 등 자유롭게 텍스트로 입력합니다.

🔍 이미지 찾기 요청

"원통형 에센스 병과 유사한 등록 디자인 찾아줘"

💬 일반 질문

"디자인권 침해 판단 기준이 뭐야?"

🌐 웹 검색 요청

"최근 화장품 용기 디자인 분쟁 사례 찾아줘"
2

AI Agent 의도 파악 → 적절한 도구로 응답

Agent가 입력된 텍스트의 의도를 자동으로 분류하고, 가장 적합한 도구를 선택하여 응답합니다.

🔍

이미지 검색 도구

유사 디자인 찾기 요청으로 판단되면 등록 디자인 DB를 검색하여 관련 이미지를 반환합니다.

💬

일반 응답

디자인권·FTO에 관한 일반 질문이면 AI가 학습된 지식을 바탕으로 직접 답변합니다.

🌐

웹 검색 도구

최신 정보나 외부 사례 검색이 필요하다고 판단되면 웹을 검색하여 관련 내용을 정리해 제공합니다.

입력한 정보는 안전하게 보호됩니다

출시 전 제품 정보는 매우 민감합니다. FTOGuard는 처음부터 보안을 최우선으로 설계했습니다.

외부 유출 없음

분석에 사용된 AI는 외부 서버로 데이터를 전송하지 않습니다. 입력 정보가 타사로 넘어갈 걱정이 없습니다.

분석 후 즉시 삭제

세션이 종료되면 입력된 제품 정보는 즉시 삭제됩니다. 데이터가 서버에 남지 않습니다.

기업 전용 환경 지원

완전 내부망 환경에서의 운용도 가능합니다. 인터넷과 완전히 차단된 상태에서도 사용할 수 있습니다.
