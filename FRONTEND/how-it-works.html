System Architecture

7단계 FTO 판단 파이프라인

FTOGuard는 특허 침해 판단의 법리를 AI가 구조적으로 해석할 수 있도록 설계된 전문 시스템입니다. 단순 유사도 검색이 아닌, All Elements Rule, 균등론, 내재성 등의 법적 원칙을 기반으로 작동합니다.

All Elements Rule 균등론 내재성 제조방법 특허

분석 프로세스

법리 기반 특허 침해 분석을 위한 체계적인 7단계 시스템

1

Query Parsing & 구조화

사용자 입력을 법리 구조로 분해하고 핵심 구성요소를 추출합니다.

구성요소 추출

제품 설명에서 핵심 구성요소를 계층 구조로 추출

입력: "스마트 보온 머그컵"
→ ["세라믹 본체", "내장 가열 소자", ...]

기술 스택

  • GPT-4o (Few-shot Prompting)
  • 법리 기반 프롬프트 엔지니어링
  • JSON 구조화 출력
2

Multi-Modal Embedding

이미지와 텍스트를 동일한 벡터 공간에 임베딩하여 유사도 검색 기반을 마련합니다.

CLIP (ViT-B/32)

이미지-텍스트 멀티모달 인코딩으로 디자인 공보와 제품 설명을 동일 공간에 매핑

ViT-B/32
3

Vector DB 검색 (FAISS)

420만 건의 특허·디자인 데이터베이스에서 유사 항목을 빠르게 검색합니다.

420만 건
특허·디자인 DB
Top-10
유사도 검색
<100ms
검색 속도
4

청구항 텍스트 임베딩 (SBERT)

특허 청구항의 법률적 의미를 보존하면서 벡터화합니다.

Fine-tuned Model

  • paraphrase-multilingual-MiniLM-L12-v2
  • 한국어 특허 도메인 특화
  • 청구항 구조 보존 학습
5

Context Retrieval (RAG)

검색된 청구항의 전체 문맥을 조회하여 정확한 판단 근거를 확보합니다. 

def retrieve_patent_context(patent_id):
    metadata = db.get_patent(patent_id)
    claims = metadata['claims']
    return claims, metadata
6

법리 기반 FTO 판단

All Elements Rule, 균등론 등 특허법 원칙을 적용하여 침해 여부를 판단합니다.

All Elements Rule

청구항의 모든 구성요소가 제품에 포함되는지 확인

균등론

실질적으로 동일한 수단, 방법으로 동일 결과 달성

내재성

명시되지 않았으나 필연적으로 포함되는 구성

제조방법 특허

물건 특허와 방법 특허의 구분 및 적용

7

결과 생성 및 시각화

분석 결과를 구조화된 리포트와 그래프로 제공합니다.

제공 정보

  • 침해 가능성 점수 (0-100)
  • 유사 특허 목록 (Top-10)
  • 구성요소별 매칭 현황
  • 법리 적용 근거
  • 회피 설계 제안
  • PDF 리포트 다운로드

이미지 vs 텍스트 분석 역할

평가위원 피드백을 반영하여 이미지와 텍스트 분석의 역할을 명확히 구분합니다.

분석 대상 사용 모델 목적 FTO 판단 역할
디자인 공보 CLIP (ViT-B/32) 외관 유사도 검색 참고용 (판단 근거 아님)
특허 청구항 SBERT + GPT-4o 법리 기반 FTO 판단 ✓ 최종 판단 근거

중요: 이미지 검색 결과만으로는 FTO 판단의 근거가 충분하지 않습니다. 특허 도면은 유사한 형태를 가질 수 있으나, 청구항의 기술적 범위는 텍스트에 의해 결정됩니다. 따라서 최종 FTO 판단은 청구항 텍스트 기반 법리 분석으로 수행됩니다.
