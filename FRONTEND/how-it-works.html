02

RDB 1차 필터링

메타데이터 기반 후보군 추출

필터링 기준

  • IPC 분류: 국제특허분류 기반 필터
  • 성분/구성요소: PostgreSQL 배열 검색
  • 유효 기간: 등록일 기준 필터링

SQL 예시

SELECT patent_id 
FROM patents 
WHERE ipc_code LIKE '%A61K%' 
  AND components @> ARRAY['세라믹','온도센서']
  AND status = '등록'
LIMIT 1000;

⚡ 효과: 420만 건 → 약 1,000건으로 후보군 축소

중요 안내

이미지 검색 결과만으로는 FTO 판단의 근거가 충분하지 않습니다.
특허 도면은 유사한 형태를 가질 수 있으나, 청구항의 기술적 범위나 핵심 구성요소는 텍스트에 의해 결정되는 경우가 많습니다. 따라서 최종 FTO 판단은 청구항 텍스트 기반 법리 분석으로 수행됩니다.
