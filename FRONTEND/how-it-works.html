작동 원리

Freedom-to-Operate 분석을 위한 AI 파이프라인 프로세스입니다.

1. 입력 데이터 처리

제품 설명이나 기술 도면을 입력받습니다. 시스템은 이 데이터를 고차원 시맨틱 임베딩으로 벡터화합니다.

2. 벡터 검색

수백만 건의 특허 청구항을 대상으로 근접 이웃 검색을 수행하여 관련 선행 기술 및 잠재적 장애 요소를 찾습니다.

3. 재정렬 (Re-Ranking)

청구항의 특정 용어와 기술 법위를 기반으로 교차 인코더 모델을 사용하여 상위 후보들을 정밀하게 재정렬합니다.

4. LLM 심층 분석

특허 전문 법률 LLM이 제품의 기능과 각 청구항 구성 요소를 개별적으로 비교하여 침해 위험도를 최종 판단합니다.

신호등 리스크 진단

최종 분석 결과는 모든 청구항 분석을 종합하여 이해하기 쉬운 리스크 점수로 제공됩니다.
