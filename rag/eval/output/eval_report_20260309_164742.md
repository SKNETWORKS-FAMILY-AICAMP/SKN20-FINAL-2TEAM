## 실험 결과 요약

- **최적 가중치**: Dense:Sparse = 1:1
  - Context Recall: **94.3%**
  - MRR: **0.744**
  - MAP: **0.612**

- 기존 설정(Dense:Sparse = 1:4 (현재)) 대비:
  - Context Recall: 91.4% → **94.3%** (+2.9%p)
  - MRR: 0.786 → **0.744** (+-0.042)

- Dense(의미 유사도)와 Sparse(BM25 키워드)를 균등하게 결합할 때 가장 높은 검색 성능을 보임
- Sparse 비중이 과도하게 높거나(3:1) 낮으면(1:4) 성능 하락
