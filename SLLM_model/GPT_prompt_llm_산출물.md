## 프로젝트 개요

- **프로젝트명**: 화장품 특허 침해(FTO) 자동 분석 시스템
- **목적**: 사용자가 제품 구성을 입력하면 특허 침해 여부를 자동으로 분석하는 sLLM 기반 소프트웨어
- **핵심 주장**: 파인튜닝된 작은 모델이 파인튜닝되지 않은 큰 모델보다 도메인 특화 성능이 뛰어남을 입증

## 활용 모델

### 베이스 모델
- **Qwen2.5 시리즈** (Alibaba Cloud)
  - Qwen/Qwen2.5-1.5B-Instruct
  - Qwen/Qwen2.5-3B-Instruct
  - Qwen/Qwen2.5-7B-Instruct (비교 대상, 파인튜닝 없음)
  - Qwen/Qwen2.5-14B-Instruct (현재 학습 중)

### 파인튜닝 방법
- **기법**: QLoRA (4bit 양자화 + LoRA 어댑터)
- **양자화**: BitsAndBytes NF4, double quantization
- **LoRA 설정**:
  - rank(r): 16
  - alpha: 32
  - dropout: 0.1
  - target modules: q_proj, k_proj, v_proj, o_proj, up_proj, down_proj, gate_proj
- **학습 환경**: RunPod A100 GPU
- **학습 프레임워크**: HuggingFace Transformers + PEFT
- **Optimizer**: paged_adamw_8bit
- **학습률**: 3e-5, warmup_ratio: 0.05
- **에폭**: 2
- **데이터**: 학습 17,377건 / 평가 4,317건 (화장품 특허 FTO 분석 데이터)

```
당신은 화장품 특허 침해(FTO) 분석 전문가입니다.

[분석 규칙]
- 구성요소 완비의 원칙: 모든 구성요소를 포함해야 침해
- 균등론: 특허 구성 수치가 경미하게 이탈 시 전문가 검토 대상
- 금반언: 등록청구항에서 삭제된 구성은 침해 주장 불가
- 내재성: 성분 동일 + 용도/효과 미언급 시 "미대응(내재성)"

[출력 형식]
◆구성 대비◆ → 테이블
◆판단◆ → 분석 설명
◆결론◆ → 4개 결론 중 하나
```

## 출력 예시

**모델 출력**:
```
◆구성 대비◆

|-------------|----------------|---------|
```
