2. clip_finetuned_best.pt
----------------------------------------------------------------
학습 스크립트 : train/clip_finetune.py
Loss          : Triplet Margin Loss (margin=0.2)

[데이터 소스]
  train/traindata/triplets.csv

[데이터 통계]
  전체 triplet 수 : 41,792개
  hard negative   : 20,318개  (같은 물품명이지만 다른 디자인, 예: 화장품 용기 vs 화장품 용기)
  easy negative   : 21,474개  (아예 다른 물품명)
  출원번호 수     : 7,397개
  물품명 종류     : 691개 (화장품 용기, 포장용기, 병, 샴푸 용기 등)

[이미지 폴더]
  data/sketch/images_v2/
  (특허 도면 스케치 이미지)

[학습 설정]
  모델       : CLIP ViT-B/32
  Epochs     : 30
  Batch      : 32
  LR         : 1e-5
  Margin     : 0.2
  Freeze     : Text Encoder 동결, 마지막 4개 Visual Transformer Block만 학습
  Sampling   : hard 70% + easy 30% (hard_ratio=0.7)
  val_ratio  : 0.1 (90% train / 10% val)
  Scheduler  : ReduceLROnPlateau (factor=0.5, patience=3)

[저장 기준]
  Epoch 28에서 val_loss 최저값으로 저장
  val_loss=0.00549 / margin_gap=0.723
